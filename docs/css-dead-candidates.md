### Known false positives in this list

- `mode-btn-off` / `mode-btn-add` / `mode-btn-replace` — emitted from
  `EngineConfigPanel.tsx:1501` inside a `${…}` template branch; the heuristic
  still misses them because the surrounding literal is split on the interpolated
  expression. **Do not delete.**
- `buried-card` — `ModelCard.tsx:219`, `ModelHubSearch.tsx:590`. **Do not delete.**
- `phosphor-screen` — only `phosphor-screen-inner` / `phosphor-display-surface`
  appear in TSX; the bare `.phosphor-screen` rules in `fusion-display.css` are
  plausibly genuine leftovers, but the AGENTS.md "Industrial display" law names
  that face, so confirm before removing.
- `text-white/80` is a Tailwind utility name inside a CSS correction hook — see
  the AGENTS.md "Container corrections must not match utility names" trap.

## Guards now enforced by `scripts/css-tools.mjs`

| Guard | Value | Behaviour |
| --- | --- | --- |
| `MAX_FILE_BYTES` | 2,000,000 | larger files skipped entirely (156 in this tree) |
| `*.min.*` / `*.map` | skipped | minified/map files never indexed |
| `MAX_LITERAL_CHARS` | 20,000 | such literals are **not** token-split; only `prefix${` / `}suffix` fragments are harvested, via bounded `[\w-]{2,64}` regexes (3,101 sites) |
| `TOKEN_RE` | `^[A-Za-z_][\w-]{0,80}$` | applied after stripping leading `.`/`#` and trailing `\ ; " ' \``; 24,310 candidates rejected |
| `MAX_TOKENS` | 500,000 | hard ceiling; on hit the audit prints a WARN naming the file where the cap was reached and keeps the partial index |
| `MAX_SCAN_FILES` | 20,000 | walk ceiling, so a runaway tree cannot hang the scan |
| `PRUNE_DIRS` | `target`, `pi-ext`, `runtime*`, `gen`, `bin`, `cache`, `config` | gitignored vendored/generated trees are not walked (this tree holds 148,612 third-party source files under `src-tauri/`) |

Semantics preserved: used / dynamic / unused tri-state, "a rule is dead only when
**every** class selector in it is unused", nested-at-rule death, second-pass
orphan-keyframe drop, and `prune` dry-run by default with `--write` to apply.

## Uncertainty / remaining risk

1. **`PRUNE_DIRS` is a judgement call beyond the literal task list.** Without it
   the walk stops at the first 20,000 files (all inside `src-tauri/target`) and
   `src/**` is never indexed — every class would read dead. With it, the index is
   362 files. If any real app class name ever lives only in a gitignored
   generated file, it will now be reported dead.
2. **Template-literal interpolation is still under-parsed.** Tokens inside
   `${cond ? "a" : "b"}` branches of a backtick literal are collected, but the
   split on the interpolation punctuation leaves escaped-quote tails; the trailing
   `\ ; " ' \`` strip fixes the common shape, yet `mode-btn-*` and `buried-card`
   still slip through as dead. Treat the whole list as needing a grep before any
   deletion.
3. **Keyframe counts differ between passes** — audit reports 6 orphan keyframes
   (862 B), prune drops 17. The extra 11 are only orphaned once the dead rules
   that referenced them are removed, which is correct behaviour but means the two
   numbers are not comparable. The prune second pass also mutates `out` inside a
   loop that re-parses per entry, so treat the keyframe list as needing a human
   check before `--write`; the byte totals are the trustworthy numbers.
4. **Attribute-hook selectors** (`[data-config-page]`, `[data-model-catalog]`)
   appear in the dead-root table because a co-occurring class is unused. The
   attribute itself is not proven unused.
5. `dist.gzip` was `null` before this change (`require()` inside ESM threw); it
   now reports 84,109 B. Any budget file comparing gzip numbers will see a value
   where it previously saw none.
